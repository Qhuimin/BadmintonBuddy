# BadmintonBuddy

A personal Python script that scans selected Telegram badminton groups and forwards game announcements that match my preferences to my Saved Messages.

## The problem

Game announcements are spread across many group chats, and organizers format them differently. Searching each chat manually takes time and exposes me to messages about games I’m not interested in.

## What it does

BadmintonBuddy parses game details from differently formatted messages, checks whether each game fits my chosen time window, level, and gender group, then forwards matching announcements to my Telegram Saved Messages.

## How it works

1. Reads messages from selected Telegram badminton groups.
2. Extracts game details from different announcement formats.
3. Checks the details against my configured preferences.
4. Forwards matching messages to Saved Messages.

## Result

The script reduces manual searching across group chats and filters out announcements that don’t match my preferences.
